Site ODS 4 é uma iniciativa criada para transformar a transição escolar e combater as desigualdades no aprendizado. Nosso foco inicial é apoiar estudantes a superarem os desafios e as lacunas no conteúdo entre o Ensino Fundamental (1 e 2) e o Ensino Médio, construindo uma base sólida para o futuro. Este protótipo é o primeiro passo de um projeto em constante evolução, que em breve se expandirá para alcançar novas áreas do conhecimento e impactar ainda mais alunos.
